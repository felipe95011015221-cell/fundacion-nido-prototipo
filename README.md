# Fundación Nido · Prototipo web

Prototipo de demostración del sitio de Fundación Nido (Medellín, Colombia).

- Las fotos son ilustrativas: escenas generadas con IA y retratos de [Unsplash](https://unsplash.com/license).
- Los perfiles del equipo son ficticios.
- Los formularios validan los datos, pero no los envían a ningún servidor.

Para verlo, abre `index.html` en el navegador o publícalo con GitHub Pages.
